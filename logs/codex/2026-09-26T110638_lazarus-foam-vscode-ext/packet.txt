=== open-node.ts CONTRACT ===

Pure domain module. NO vscode import. NO node:fs import. NO side effects.

Imports:
- isNodeId from '@foam/graph-view/protocol' (use same @ts-expect-error ESM pattern as roots.ts:3-4)
- type NodeId from '@foam/graph-view/protocol' with { 'resolution-mode': 'import' }
- type URI from '@foam/core'
- type PrivacyPolicy, DenyReason from './privacy'

Export a discriminated union result type:

```typescript
export type OpenNodeDeny =
  | { allowed: false; reason: 'invalid_id' }
  | { allowed: false; reason: 'unknown_id'; nodeId: NodeId }
  | { allowed: false; reason: 'stale_mapping'; nodeId: NodeId; uri: URI }
  | { allowed: false; reason: 'privacy_denied'; nodeId: NodeId; uri: URI; denyReason: DenyReason };

export type OpenNodeAllow = { allowed: true; nodeId: NodeId; uri: URI };

export type OpenNodeResult = OpenNodeAllow | OpenNodeDeny;
```

Export the main function:

```typescript
export function resolveNodeOpen(
  payload: unknown,
  idToUri: Map<NodeId, URI>,
  policy: PrivacyPolicy,
  isInWorkspace: (uri: URI) => boolean
): OpenNodeResult
```

Validation order (EXACT, each check runs only if prior checks pass):
1. `!isNodeId(payload)` => `{ allowed: false, reason: 'invalid_id' }`
2. `idToUri.get(payload)` miss => `{ allowed: false, reason: 'unknown_id', nodeId: payload }`
3. `!isInWorkspace(uri)` => `{ allowed: false, reason: 'stale_mapping', nodeId: payload, uri }`
4. `uri.scheme !== 'file'` OR `!policy.decide(uri.toFsPath()).allowed` => privacy_denied with the inner DenyReason from the decision (for non-file scheme use 'outside_roots' as denyReason)
5. else `{ allowed: true, nodeId: payload, uri }`

Step 4 calls policy.decide() fresh every time — never cache.
