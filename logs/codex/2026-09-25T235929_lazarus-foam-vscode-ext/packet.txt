=== webview-security.ts ===

Import: only node:crypto (for randomBytes). No vscode import. No other runtime deps.

Exports:

  generateNonce(): string
    - Returns a 32-byte random hex string via crypto.randomBytes(32).toString('hex').

  buildCsp(params: { cspSource: string; nonce: string }): string
    - Returns this exact CSP string (one line, semicolons separating directives):
      "default-src 'none'; script-src 'nonce-${nonce}'; style-src ${cspSource} 'unsafe-inline'; img-src ${cspSource}; font-src ${cspSource}"
    - The 'unsafe-inline' in style-src is required because force-graph 1.51.4 injects a runtime style element.

  fillGraphHtml(template: string, params: { csp: string; nonce: string; resolveAsset: (filename: string) => string }): string
    - Replaces __PA_HUB_CSP__ with params.csp (exactly 1 occurrence in the template).
    - Replaces __PA_HUB_NONCE__ with params.nonce (exactly 2 occurrences in the template: one on link, one on script).
    - Replaces data-replace attributes: pattern /data-replace (src|href)="[^"]+"/g
      For each match: extract the filename from the quoted value, call resolveAsset(filename), replace the whole match with just the attribute (src or href) = resolved URI.
      Example: data-replace src="./main.js" becomes src="https://webview-uri/main.js"
    - Returns the filled HTML string.

The template to fill is the built index.html at static/dataviz/index.html (N09 output):
```html
<!DOCTYPE html>
<html>
  <head>
    <meta http-equiv="Content-Security-Policy" content="__PA_HUB_CSP__" />
    <meta charset="utf-8" />
    <link data-replace href="./main.css" rel="stylesheet" nonce="__PA_HUB_NONCE__" />
  </head>
  <body>
    <div id="app"></div>
    <script data-replace src="./main.js" nonce="__PA_HUB_NONCE__"></script>
  </body>
</html>
```
